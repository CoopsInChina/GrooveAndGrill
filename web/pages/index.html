Install firmware over USB — no software required

  1. Plug the display into this computer via USB-C.
  2. Click the button below and pick the device's serial port.
  3. Wait for the flash to finish, then the device reboots on its own.

Needs Chrome or Edge (Web Serial support). Firefox and Safari aren't supported.

Already running Groove & Grill? Use Settings → OTA Update on the device instead — no cable needed.
